# Предсказание калорийности блюд по фото и составу

## Цель
Обучить нейросеть, которая по фотографии блюда и списку ингредиентов предсказывает его калорийность.

## Датасет
Ссылка: https://disk.yandex.ru/d/kz9g5msVqtahiw

- 3262 блюда (train 2755 / test 507), 555 ингредиентов.
- У каждого блюда есть фото 640×480 и список ингредиентов.
- Данные в репозиторий не коммитятся — скачиваются по ссылке.

## Структура репозитория
```
project/
├── data/             
├── scripts/
│ ├── config.py       # гиперпараметры
│ ├── dataset.py      # датасет, парсинг ингредиентов, аугментации
│ └── utils.py        # модель, train(cfg), инференс
├── notebook.ipynb    # EDA, обучение, валидация на test
└── README.md
```
